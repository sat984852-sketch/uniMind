# UniMind

## مرحله‌ی چهارم: داشبورد دانشجو (تازه اضافه شد)
- `dashboard.php` — داشبورد واقعی: خوشامدگویی با تاریخ شمسی، تعداد جزوه‌ها، تعداد گفت‌وگوها، زمان مطالعه، برنامه‌ی مطالعه‌ی پیش رو، فعالیت‌های اخیر و دسترسی سریع. همه‌ی عددها مستقیم از پایگاه داده می‌آن
- `includes/app_header.php` + `app_footer.php` — قالب بخش بعد از ورود (منوی کناری + نوار بالا)
- `includes/sidebar.php` — منوی کناری؛ بخش‌هایی که هنوز ساخته نشدن با برچسب «به‌زودی» غیرفعال‌ان (لینک مرده نداریم)
- `includes/helpers.php` — تاریخ شمسی، ارقام فارسی، فرمت زمان، و لیست بخش‌های برنامه (وقتی صفحه‌ای ساخته شد، فقط `'ready' => true` می‌شه)

### تست کردن
بعد از ورود، داشبورد باید اسمت و تاریخ امروز (به شمسی) رو نشون بده. چون هنوز داده‌ای نداری، همه‌ی عددها ۰ و پنل‌ها خالی‌ان. برای دیدن اینکه داده‌ی واقعی نمایش داده می‌شه، توی phpMyAdmin یه ردیف دستی به جدول `study_plans` اضافه کن (user_id = شماره‌ی خودت، title، plan_date = تاریخ امروز یا بعدش).

## مرحله‌ی سوم: ثبت‌نام، ورود و خروج (تازه اضافه شد)
- `includes/auth.php` — مدیریت نشست (session)؛ تابع `require_login()` روی هر صفحه‌ی محافظت‌شده صدا زده می‌شه
- `api/register_handler.php` — اعتبارسنجی، بررسی تکراری‌نبودن ایمیل، `password_hash`، درج در جدول `users`
- `api/login_handler.php` — بررسی ایمیل/رمز با `password_verify`، جلوگیری از session fixation
- `api/logout.php` — پاک کردن کامل نشست
- `dashboard.php` — یه صفحه‌ی خیلی ساده که فقط نشون می‌ده ورود/ثبت‌نام کار می‌کنه؛ طراحی کامل داشبورد در مرحله‌ی بعدیه
- فرم‌های `login.php`/`register.php` الان خطاها رو واقعی نشون می‌دن (مثلاً «ایمیل تکراریه» یا «رمز کوتاهه»)

### تست کردن
1. برو `register.php`، یه حساب بساز
2. باید خودکار بری به `dashboard.php` و اسمت رو ببینی
3. روی «خروج از حساب» بزن، برگرد `login.php` و با همون ایمیل/رمز وارد شو

## مرحله‌ی دوم: پایگاه داده
- `database/unimind.sql` — اسکیمای کامل، هر ۱۱ جدول (users, subjects, exams, notes, note_chunks, conversations, messages, study_plans, quizzes, quiz_questions, quiz_results) با کلید خارجی بین‌شون
- `config/database.php` — اتصال PDO؛ فقط همین فایل تنظیمات پایگاه‌داده رو نگه می‌داره

### چطور اجراش کنی (Laragon)
1. Laragon رو اجرا کن (MySQL باید روشن باشه)
2. برو به `http://localhost/phpmyadmin`
3. روی **Import** بزن → فایل `database/unimind.sql` رو انتخاب کن → **Go**
   (خودش دیتابیس `unimind` رو می‌سازه، نیازی به ساخت دستی نیست)
4. تنظیمات پیش‌فرض `config/database.php` (`root` بدون پسورد) با Laragon سازگاره؛ معمولاً نیازی به تغییر نیست

### وقتی رفتی روی InfinityFree (یا هر هاست دیگه)
فقط ۴ خط بالای `config/database.php` (DB_HOST, DB_NAME, DB_USER, DB_PASS) رو با اطلاعاتی که همون هاست بهت می‌ده عوض کن — بقیه‌ی کد دست‌نخورده می‌مونه.

# UniMind — مرحله‌ی اول: رابط کاربری و صفحات اصلی

## چی توی این مرحله ساخته شده
- `index.php` — صفحه‌ی اصلی (معرفی، امکانات، روند کار، CTA)
- `login.php`, `register.php` — صفحات ورود و ثبت‌نام (فعلاً فقط UI + اعتبارسنجی سمت کاربر؛ فرم‌ها به `api/login_handler.php` و `api/register_handler.php` ارسال می‌شن که در مرحله‌ی بعد ساخته می‌شن)
- `includes/header.php`, `includes/footer.php` — قالب مشترک صفحات عمومی
- `includes/sidebar.php` — فعلاً خالی؛ در مرحله‌ی داشبورد تکمیل می‌شه
- `assets/css/style.css` — تم رنگی آبی‌تیره/فیروزه‌ای، کاملاً راست‌چین و واکنش‌گرا
- `assets/js/main.js` — فقط منوی موبایل؛ منطق فرم‌ها در مرحله‌ی بعد اضافه می‌شه

## چیزی که هنوز کار نمی‌کنه (عمداً، طبق برنامه‌ی مرحله‌به‌مرحله)
- فرم ورود/ثبت‌نام چیزی ذخیره نمی‌کنه (هنوز پایگاه داده و `config/database.php` ساخته نشده)
- `config/`, `api/`, `database/` فعلاً خالی‌ان

## اجرا با Laragon
1. این پوشه (`UniMind`) رو بذار داخل `laragon/www/`
2. Laragon رو اجرا کن (Start All)
3. برو به آدرس `http://unimind.test` یا `http://localhost/UniMind`

مرحله‌ی بعدی: طراحی پایگاه داده (MySQL) و اتصال PHP به اون.

# مرحله‌ی ۴ — چت هوشمند (DeepSeek)

فایل‌های جدید: `chat.php`، `assets/js/chat.js`، `api/chat.php`، `api/history.php`، `api/delete.php`، `config/ai.php`، `config/.htaccess`، `includes/ai_client.php`، `includes/csrf.php`

## نصب
1. پوشه‌ی `UniMind` رو جایگزین پوشه‌ی قبلی توی `laragon/www/` کن. دیتابیس تغییری نکرده؛ دوباره import نکن.
2. توی Laragon بزن Start All.
3. فایل `config/ai.php` رو باز کن و کلید رو بذار:
   `'api_key' => 'کلید-خودت',`
   (کلید رو از platform.deepseek.com بخش API keys بگیر؛ حساب باید موجودی داشته باشه.)
4. وارد شو و برو `localhost/UniMind/chat.php` (یا «گفت‌وگو با دستیار» توی منوی کناری).

## تست اتصال واقعی
1. یه پیام بفرست، مثلاً «تفاوت stack و queue چیه؟». باید «در حال پاسخ‌گویی…» ببینی و بعد جواب واقعی.
2. صفحه رو رفرش کن؛ گفت‌وگو باید توی لیست «گفت‌وگوهای قبلی» باشه.
3. جدول `messages` توی phpMyAdmin باید پیام کاربر و جواب رو داشته باشه.
4. تست خطا: کلید رو عمداً غلط بذار؛ باید پیام «کلید API اشتباهه» بیاد و چیزی ذخیره نشه.

## اگه خطا گرفتی
- «خطای گواهی SSL»: فایل cacert.pem رو از curl.se/ca/cacert.pem دانلود کن و مسیرش رو در `ca_bundle` فایل `config/ai.php` بذار.
- «اتصال برقرار نشد»: اینترنت یا VPN رو چک کن (api.deepseek.com باید از سیستمت باز بشه).
- «پارامترهای نامعتبر»: اسم مدل (`model`) رو طبق مستندات api-docs.deepseek.com عوض کن.

# مرحله‌ی ۵ — پروفایل، جزوه‌ها، برنامه‌ی مطالعه

فایل‌های جدید: `profile.php`، `notes.php`، `planner.php`، `api/note_download.php`، `uploads/.htaccess`
فایل‌های تغییرکرده: `includes/helpers.php`، `includes/csrf.php`، `assets/css/style.css`
دیتابیس تغییری نکرده (دوباره import نکن).

## تست روی Laragon
1. **برنامه‌ی مطالعه:** یه درس اضافه کن، بعد یه برنامه برای فردا بذار (مثلاً ۱۶:۰۰ تا ۱۷:۳۰). برنامه‌ی همپوشان باید خطا بده. تیک ✓ رو بزن تا «انجام شد» بشه. توی داشبورد هم باید برنامه‌ی پیش رو رو ببینی.
2. **جزوه‌ها:** یه PDF آپلود کن، «باز کردن» و «دانلود» رو بزن، بعد حذفش کن. فایل‌های `.php` و `.exe` باید رد بشن.
3. **پروفایل:** اسمت رو عوض کن (توی منوی کنار هم عوض می‌شه) و رمز رو عوض کن؛ بعد خروج بزن و با رمز جدید وارد شو.
4. **امنیت پوشه‌ی uploads:** آدرس `localhost/UniMind/uploads/1/` رو توی مرورگر باز کن. باید «Forbidden / ۴۰۳» ببینی.

## هنوز «به‌زودی»
- ساخت آزمون (به جزوه‌ها وصل می‌شه و بهتره بعد از پایدار شدن چت بسازیمش)

## آنلاین کردن (هاست PHP/MySQL مثل InfinityFree)
1. توی پنل هاست یه دیتابیس MySQL بساز (اسم، کاربر و رمز و آدرس سرور رو یادداشت کن).
2. توی phpMyAdmin همون هاست، دیتابیس رو انتخاب کن و فایل `database/unimind_hosting.sql` (نه `unimind.sql`) رو Import کن.
3. توی `config/database.php` چهار خط بالا (DB_HOST, DB_NAME, DB_USER, DB_PASS) رو با اطلاعات هاست عوض کن.
4. توی `config/ai.php` کلید رو بذار.
5. همه‌ی فایل‌های پوشه‌ی UniMind رو (از جمله فایل‌های `.htaccess`) توی پوشه‌ی `htdocs` هاست آپلود کن.
6. SSL (https) رو از پنل هاست فعال کن.
⚠️ پروژه رو با کلید واقعی روی گیت‌هاب عمومی نذار.
